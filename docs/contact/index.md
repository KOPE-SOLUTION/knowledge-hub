## แนวทาง LINE สำหรับเฟสแรก

แนะนำให้สร้าง **LINE Official Account (LINE OA)** สำหรับ KOPE SOLUTION แยกจาก LINE ส่วนตัว เพื่อรักษาความเป็นส่วนตัว แยกบทสนทนางาน และรองรับการดูแลลูกค้าในอนาคต ระหว่างที่ยังไม่มี URL หรือ QR code จริง เว็บไซต์จะแสดง placeholder และจะไม่สร้างลิงก์ LINE ปลอม

ในเฟสแรก LINE จะเป็นช่องทางเดียวสำหรับ **สอบถามสินค้าและแจ้งความประสงค์สั่งซื้อ** เว็บไซต์ยังไม่มี cart, checkout, payment gateway หรือระบบเก็บข้อมูลลูกค้า รายละเอียดสินค้า ราคา วิธีชำระเงิน และเงื่อนไขต่าง ๆ ต้องได้รับการยืนยันก่อนใช้งานจริง

## ก่อนเผยแพร่ช่องทางติดต่อ

- ใช้ account หรือ email สำหรับสาธารณะโดยเฉพาะเมื่อเหมาะสม
- ตรวจว่า URL ใช้งานได้และเป็น account ของ KOPE SOLUTION จริง
- ระบุเวลาตอบกลับหรือเงื่อนไขเฉพาะเมื่อมีข้อมูลจริงเท่านั้น
- เมื่อเปิดขายจริง ให้เผยแพร่เฉพาะ LINE OA URL/ID/QR code ที่เจ้าของยืนยันแล้ว
